# OSPF authentication inheritance and overrides

The router and routed Catalyst profiles now consume `area <id> authentication [message-digest]` as the default for interfaces in that area. An explicit interface authentication mode takes precedence. `ip ospf authentication null` disables authentication on that interface; removing the override restores area inheritance. Dotted and numeric area identifiers resolve to the same effective area. Interface key-chain selection replaces the explicit mode and removing it restores the inherited setting.

The effective mode and selected keys are carried by the existing delivered OSPF Hello records. Mismatched modes or keys prevent adjacency, LSDB exchange and route installation. Matching remote configuration cannot create an adjacency while the control packets are lost. `show ip ospf interface` displays the effective simple, message-digest or unauthenticated state without exposing keys.

Virtual links inherit backbone-area authentication unless explicitly overridden. Their bounded logical compatibility check supports simple keys, MD5 key IDs, configured key chains and `authentication null`. Successive virtual-link commands merge settings. Removing one authentication option/key preserves the virtual link; removing the bare link deletes it. Rendering retains separate key commands for replay.

`tests/ospf-area-auth.test.ts` checks real received Hellos, route withdrawal/recovery, ICMP traffic, one-way packet loss, router/L3-switch interoperability, simple and MD5 modes, interface null overrides, dotted-area identity, invalid-input atomicity, help, startup/project persistence and virtual-link authentication dependencies. The broader routing and terminal suites retain their existing assertions. These are logical authentication records, not cryptographic MD5/HMAC wire interoperability. The virtual-link path remains the documented bounded virtual-edge model; it is not a complete native OSPF virtual-interface transport.

They establish area defaults, interface overrides and virtual-link forms; no unavailable native output fixture is invented.
