# Compatibility and verification limits

NetworkSim is an original offline teaching simulator. It does not execute Cisco IOS, Windows, Ubuntu, macOS, native Ansible or vendor controller software. Passing the acceptance suite establishes the asserted simulation contracts; it does not establish every native command option, byte format, hardware behavior or possible exam Simlet.

## Evidence boundaries

- The current command sweep records exact node/path/handler selection, positive/no/default representatives, help/completion purity and known-invalid atomicity. A selected shared show formatter is distinguished from executing the registered function body. Representative coverage does not certify every argument/default/abbreviation combination.
- The older sandbox is executed read-only for comparison. Agreement with it is not Cisco equivalence. Its 492 reference source hashes are retained independently; no old implementation is bundled in the product.
- REA retained genuine Packet Tracer9.0.1 ISR4331 observations, whose emulated IOS reports16.6.4. No real IOS XE17.12/CML or native Windows/Ubuntu/macOS reference runtime was available. Primary vendor documentation supplies stated teaching abstractions; unavailable runtime goldens are never invented.
- The objective matrix indexes all284 numbered parent/child objectives across current CCNA1.1, published CCNA2.0, ENCOR1.2 and ENARSI1.1. Exact practical-case ledgers identify asserted workflows separately from broad subsystem candidates. Complete native exam coverage is not inferred from lexical matches.
- The continuation has an immutable source archive and exact byte/registry deltas. The earlier overall audit did not have that original baseline. Shared concurrent work is retained without assigning invented authorship.

## Protocol and platform bounds

- STP/RSTP/MST, DTP, LACP/PAgP and VTP decisions now use delivered structured control records. MST region boundaries are conservative per-VLAN approximations; there is no full CIST/M-record or mux/marker state-machine implementation. The stated silent-neighbor STP transition is a teaching bound. VTPv3 primary-server negotiation, pruning and binary summary/subset segmentation remain unsupported.
- EIGRP uses reliable delivered INIT/UPDATE/ACK vectors, retries and QUERY/REPLY/SIA integration for classic/named IPv4/IPv6 and VRFs. Full native DUAL corner cases, numerical calibration and binary RTP encoding are not certified. OSPF uses received Hellos/LSDB records, with bounded area/LSA adapters and virtual-edge behavior. BGP uses persistent simulated TCP and received updates, with an incomplete full vendor event/SAFI catalog.
- Optional copper/fiber reach, media, faults and frame-length bit-error sampling affect real carrier/CRC/traffic. They assume matching optics and do not reproduce analog signaling, auto-MDIX internals, optical DOM, ASIC/TCAM partitions or collision backoff. The32,000-entry shared switch CAM profile uses deterministic static reservation/eviction rather than ASIC hash collisions.
- Output queues schedule actual traffic: class weights, LLQ, shaping, per-flow fair queues, WRED/ECN and drops. The selected router curves/idle decay/bucket limits are documented teaching defaults; full hierarchy, native TCP ECN congestion response and hardware queue calibration are absent. Router WRED/fair-queue syntax rejects on Catalyst profiles.
- IPv6 FHRP, complete DMVPN phase3 signaling, MPLS/VPN SAFIs, full IPv6 multicast/MLD, arbitrary route-policy expressions and native hardware resource catalogs remain partial or unsupported. Describe-only objectives are not silently expanded into full product implementations.
- WLC administration/monitoring, AAA, NTP/syslog/SNMP, AP authorization, save/reload, ACL/QoS bindings, client disconnect, tags and WLAN workflows have real state/packet effects. These are relevant teaching pages, not the complete Cisco GUI. Certificate/image workflows, full RRM/DFS/regulatory behavior, inter-controller mobility and controller HA are not reproduced.
- Wireless supports lightweight control and an explicit generic standalone profile, logical WPA2/WPA3/transition/PMF, RF and local/central bridging. It does not execute SAE/EAP/AES/DTLS cryptography or native autonomous firmware, and does not model6GHz, all RF contention/retries or fast/inter-controller roaming.
- APs remain exclusively PoE-powered. The selected30W PoE+ profile supports full APs, explicit15.4W reduced APs, and generic class3 phone/printer/IoT powered endpoints. Higher-power802.3bt/UPOE, analog detection, electrical/CDP power negotiation and instantaneous consumption measurements are outside that selected profile. A phone role models edge attachment and discovery, not SIP/RTP call control or audio.
- Windows, Ubuntu24.04 and macOS15 consoles are bounded networking subsets sharing the actual host stack. No full shell/kernel, OS service/process administration, NetBIOS/WINS or every native command option/output is implemented. Native UDP traceroute is not silently replaced: the Unix subset requires the native ICMP `-I` option.
- SNMP supports logical read-only v2c/v3 GET/GETNEXT/GETBULK, actual notifications/inform acknowledgments, views/identities and persistent ifIndex. It does not implement BER/USM cryptography, timeliness/replay security, writable/full vendor MIBs, SNMPv1 or all VRF/context/transport details. Packet sizing uses a logical estimate, not BER bytes.
- FTP configuration transfers use real simulated control/passive data TCP channels and bounded UTF-8 text files. Active FTP, IPv6 FTP, TLS/FTPS, arbitrary binary files and an IOS FTP server are not provided.
- SSH/TLS/IPsec security and SCP/SFTP transport are logical teaching models. IOS SCP transfers use actual simulated TCP and authorization; files are bounded text and no firmware executes. DNS is authoritative service plus resolver cache, not a complete recursive zone server.
- **User-approved exclusion, October16,2026:** preserve the removal of Server TFTP and SCP/SFTP listeners, their administration pages and the desktop File Transfer tool. Old file dictionaries remain, but those Server listeners stay disabled even when legacy flags are enabled. IOS SCP and retained protocol APIs are separate capabilities. The SFTP portion of a complete secure-file-transfer lab remains explicitly constrained by this exclusion.
- NETCONF/RESTCONF expose a bounded interfaces/hostname datastore and defined RPCs, not general YANG compilation, NETCONF1.1 or interoperable SSH/TLS. Automation is an offline Ansible-compatible teaching subset over actual simulated SSH, without Python/Jinja/roles/collections or a native Ansible runtime.
- Actual Catalyst Center/DNA Center Assurance, SD-WAN Manager, cloud products, hypervisors and containers are not embedded. External-product practical objectives require those environments; a static substitute is not labeled complete. NTP/PTP, accounting, hardware boot/redundancy and retained compatibility knobs have subsystem-specific bounds. PTP election does not synchronize clocks, and SSO does not emulate redundant processors.

The source-bound inventories, exact practical-case ledgers, subsystem reports and final acceptance log make these distinctions inspectable. `show capabilities` reports current implemented and unsupported behavior from inside the app.
