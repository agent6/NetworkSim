# Physical media, MAC capacity and reduced-power PoE

The link editor now offers optional Cat5e, Cat6A, OM3/SR and single-mode/LR teaching profiles with length, open/short/miswire faults and bit error probability. Existing projects retain their ideal-link behavior unless a physical profile is selected.

Cable category, supported speed, maximum length, selected interface media and physical faults feed Ethernet carrier state. Carrier changes remove connected routes and protocol reachability through the existing engine. Propagation adds length divided by an assumed200million metres per second. Bit errors are sampled from actual frame length using the seeded simulation RNG; damaged frames increment the receiving interface's CRC/input-error counters and do not reach its protocol stack. Administrative shutdown and generic packet loss remain separate controls.

The stated reach limits are100m for the copper profiles,300m for10Gbps OM3/SR,550m for1Gbps OM3 and10km for single-mode/LR. The fiber choice assumes matching optics; this is not an implementation of vendor SFP inventories, optical DOM, analog attenuation, wavelength selection, FLP, calibration or hardware registers. Miswire represents an incorrect pin mapping/polarity fault, rather than claiming modern auto-MDIX rejects a valid crossover cable. `media-type` now affects the selected cable's compatibility, and interface diagnostics expose its profile, length and observed failure reason.

The L2/L3/PoE C9300-style profiles share a32,000-entry MAC budget across VLANs. At capacity, new dynamic learning stops while valid unknown unicast still floods. Existing entries can move/refresh, expired entries release capacity, and static reservations displace an old dynamic entry. Static over-capacity reservations are counted as uninstalled. This is a shared CAM limit; it does not reproduce ASIC hash collisions, TCAM partitions or every hardware resource table. Runtime learning is never serialized as configuration.

PoE remains the AP's only power source. Default PoE+ ports reserve30W for the full4×4 C9115 teaching profile. An explicitly limited port with15400–29999mW available allocates15.4W at the PSE for802.3af reduced mode, with2×2 radios and USB disabled. Below15400mW the AP is denied. A full-power port is not silently downgraded to avoid a depleted switch budget. Priority/detection-order shedding and per-port auto/never controls remain operational. Open/short copper faults, fiber links and copper beyond the modeled100m reach cannot supply AP power; removing supply runs the normal AP/client/CAPWAP lifecycle. A short is reported as a fault.

`tests/link-medium.test.ts` covers media/speed/reach boundaries, physical fault/recovery routes and packets, traffic-driven CRC errors, media CLI/reset/reload, actual PoE loss and validated save/load. `tests/mac-capacity.test.ts` covers all three switch profiles, cross-VLAN capacity, refresh/aging/static reservation and real flooding under exhaustion. `tests/poe.test.ts` includes reduced class/power/traffic/persistence tests in addition to existing power-budget, priority, loss/recovery and no-local-power regressions. The wireless management suite checks the reduced spatial-stream consumer and effective client rate.
