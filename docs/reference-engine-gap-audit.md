## Reviewed families without an additional confirmed gap in this pass

The inspected reference assertions for actual IPv4/IPv6 forwarding/TTL, DF/MTU behavior, interface EtherChannel flow selection, normal recursive/static route forwarding, ARP resolution, QoS mark/police, pool exhaustion/PAT return translation, basic time ranges, DHCP relay/Option82, NTP preference/reach/loop rejection, GRE and simulated IPsec negotiation/protection have corresponding original implementations and tests. This statement is bounded to the inspected assertions. It is not a claim of full standards compliance or exhaustive reference parity.

Reference tests directly manipulate internal paths/weights in some CEF cases. Those cases establish a forwarding-model requirement, not automatically a requirement for every unsupported IOS command. Conversely, a parsed configuration line alone does not establish working runtime behavior. The broader IOS exclusions in `engine-coverage.md` should be kept separate from the concrete reference gaps listed here.
