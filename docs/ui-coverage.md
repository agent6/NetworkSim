# Interface and local workflow coverage

The interface is original TypeScript with locally compiled Tailwind CSS and embedded device artwork and SVG toolbar icons. The runtime is packaged into `index.html`. It has no account, cloud storage, CDN, native simulator dependency, server API or external network service. See [validation.md](validation.md) for observed browser checks and the file-URL testing limitation.

| Reference workflow | New implementation | Verification and limits |
| --- | --- | --- |
| Device palette | Routers, L2/L3 switches, PCs and servers; original icons; click or drag onto canvas | Browser exercised click-to-add. Model factories and independent packet tests use all five kinds. Drag is implemented but not exhaustively gesture-tested. |
| Topology editing | Rename, drag, center/equal-spacing guides, Alt snap bypass, shift/marquee selection, lock, copy/cut/paste, duplicate with internal cables, inline notes, 80-step undo/redo | Browser verified center and equal-spacing snapping, Alt free placement, note editing/cancellation/locking, rename undo/redo and cabling. Independent alignment tests cover zoom tolerance and spacing geometry. Paste enforces the 100-device/100-note/300-link limits and assigns distinct names/IDs. |
| Cabling and power | Available-port selection, cable settings, latency/loss and independent directional loss; individual/all-device power | Browser verified endpoint selection and save-before-power-off. Engine tests cover power/startup, in-flight invalidation and directional faults. |
| View and accessibility | Pointer-centered wheel zoom, Space/middle-button pan, fit/reset, context menus, responsive palette, collapsible/resizable dock, keyboard nodes/links/notes, dialog focus trapping/restoration, live status, escaped imported text | Desktop and 390-pixel viewport observed. Native button Space and keyboard separator resizing checked. Touch pinch/drag/long-press are implemented but not manually tested on physical touch hardware. |
| CLI | One scrolling terminal with an inline prompt, per-device drafts/history/scroll position, IOS modes, completion/help at caret, line editing, batch paste, paging, hidden secret entry, copy and live terminal-monitor logs | Browser tested terminal focus, draft restoration, history, line editing, paste, scrollback restoration, paging, completion, interactive extended ping and live BGP inspection. Parser/management tests cover authentication, remote escape/resume, lifecycle and error paths. |
| Host desktop | IPv4/IPv6 static configuration, explicit manual/automatic modes that stop old renewals, DHCP/DHCPv6/SLAAC requests, command prompt and simulated browser | Browser and engine examples verify addressing, DNS and HTTP. Manual link-local/EUI-64 commands are also supported by CLI. |
| Simulated browser | Go/Back, scoped lab HTTP login, actual DNS/HTTP/TCP requests, HTML/CSS/images from simulated servers; scripts and external resources blocked | Browser verified linked page, stylesheet appearance and Back navigation. It is a teaching browser for local lab pages, not a general internet browser. |
| Services | DNS A/AAAA records, DHCP pools/exclusions, HTTP pages/authentication/flash base paths/local users, RADIUS/TACACS lab users, NTP, TFTP and syslog | Browser exercised HTTP and AAA editing. Protocol tests establish actual service delivery and negative paths. |
| Local persistence | Automatic workspace recovery after reload, download/open `.netsim.json`, named browser save/open/rename/delete/download, share codes, import validation/rollback | Active workspace checkpoints preserve configurations, notes, links and viewport independently of named saves. Pending edits flush before reload. Independent tests cover recovery, empty labs, storage failures, malformed input, duplicate IDs, limits, prototype keys and invalid configuration. Browser storage can be unavailable for local files; export remains available. |
| Lab objectives | Eight original examples, declarative conditions, live configuration checks, remembered delivered-traffic checks, completion report and reduced-motion-aware celebration | Tests require actual replies and keep configuration conditions live. Imported conditions are bounded and validated; no imported scripts execute. Empty labs start without objectives. |
| Simulation controls | Run/pause/single event and speed | Dedicated packet-testing controls, event views, and the packet inspector were removed at the user's request. Connectivity checks use the device console. |

Browser-local saves use a new format and preserve running and startup configuration separately. A simulated network-device reboot loads startup configuration or factory defaults. Host desktop settings persist. Runtime queues and protocol sessions rebuild on import; a file is not a full live-memory snapshot. Cisco `.pkt`/`.pka` and the supplied sandbox's legacy format are not accepted.

The interface coverage does not certify every IOS command or protocol behavior. Remaining networking differences are tracked in [cli-coverage.md](cli-coverage.md), [engine-coverage.md](engine-coverage.md) and [protocol-design.md](protocol-design.md).
