# REA research and reconstruction boundaries

The simulator is an original implementation. Neither Packet Tracer code, bundled artwork, binaries, nor the supplied sandbox's source or assets are included in the application. The user authorized inspecting both references and explicitly requested a fresh implementation of the sandbox too. Packet Tracer is a research reference; the resulting HTML does not invoke or require its installation.

REA 6.5.0 was installed with Node 24.22.0 and its Codex MCP server was checked successfully. The installed `reverse-engineer-anything` workflow drove artifact identification and evidence retention. The inspected artifact was `/Applications/Cisco Packet Tracer 9.0.1/Cisco Packet Tracer 9.0.1.app/Contents/MacOS/PacketTracer`, SHA-256 `4ec895db0a5632e8c53da56d7785513d2e80d8c7893a0e6d3bb11202f2d2eb0a`. REA selected the ARM64 slice of the universal Mach-O. The bundle identifier is `com.netacad.PacketTracer9.0.1`.

REA `inspect_macho` produced native artifact evidence `ev_0af5b9e8d28fa68071fe93922c30899bf5e8a962678407ab630bc3508d19b563` and derived summary `ev_d95c5e0034ff2ff6f552aedda6472826a9262d67b75336aa4908abd1d64d2a98`. The raw evidence bundle is retained under ignored `.research/packettracer-rea.json` for local investigation; it is not part of the build. Static inspection identified 39 dependencies, 57 load commands and substantial exported C++ metadata. Export coverage is not exhaustive and does not prove that a specific feature behaves correctly at runtime.

Relevant native metadata includes a simulation scheduler with next-event expiration, current simulation time, cancellation cleanup and an expiration-count limit. It also includes separate IPv4 fragmentation/reassembly processing, DF-based drop handling and reassembly flush timers. This supports investigating those architecture boundaries; it does not establish their algorithms. No native procedure bodies were copied or translated into the new engine.

Packet Tracer's bundled help describes VLAN-scoped MAC learning and aging, STP/RSTP roles, TCP state/sequence/window behavior, and a master simulation time shared between realtime and event stepping. It explains that clearing the event list is distinct from resetting network state. The new simulator applies these concepts through independently written models and tests.

Native accessibility observation of Packet Tracer timed out in this environment. Therefore there is no claim of live, side-by-side Packet Tracer behavioral equivalence. The supplied sandbox was inventoried separately as ordinary source-reference research. Its behavioral defects and acceptance inventory are documented in `reference-engine-audit.md` and `reference-feature-inventory.md`.

The new implementation uses a deterministic event heap, stable ordering, bounded advancement, seeded randomness, cancellation generations, a packet event ledger, interface-level forwarding, real return-path checks, and explicit MTU/DF/fragmentation behavior. Public protocol references and the corresponding limitations are recorded in `protocol-design.md`. Passing selected tests does not establish full IOS or full sandbox parity.
