## Evidence boundaries
Explicit case IDs above point to reviewed assertions in the JSON caseEvidence registry, with exact test file locations/hashes and what each case does and does not show. Other rows remain candidate source/test mappings; names alone do not prove implementation. External controller, cloud, hypervisor and OS components remain separate from simulated network configuration. All statuses remain bounded or conceptual; zero complete exam objectives are certified.

Server TFTP/SCP/SFTP administration and Desktop File transfer are intentionally excluded. IOS-to-IOS file operations remain available through IOS copy; passive IPv4 FTP has a separate Server service form. The Automation tab is an offline teaching subset and does not restore those server services.
